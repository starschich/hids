\section{Testing and acceptance}

\subsection{Test stages}
\begin{itemize}\setlength{\itemsep}{0.2em}
  \item \textbf{TA-1} Type tests and factory acceptance tests (FAT) for major
        equipment (converter transformer, valves, control \& protection).
  \item \textbf{TA-2} Control-system verification on a real-time simulator
        (e.g.\ RTDS) prior to commissioning.
  \item \textbf{TA-3} Site acceptance tests (SAT) and subsystem commissioning.
  \item \textbf{TA-4} System commissioning, trial operation and the performance
        (availability/loss) demonstration over the agreed period.
\end{itemize}

\subsection{Acceptance criteria}
\begin{itemize}\setlength{\itemsep}{0.2em}
  \item \textbf{TA-5} All functional requirements (Section~3) demonstrated.
  \item \textbf{TA-6} Performance requirements (Section~4) met, with losses and
        response times within the specified limits.
  \item \textbf{TA-7} Documentation, spares and training delivered per the
        contract.
\end{itemize}
