# Glyphwright symbol library for LaTeX

IEC 60617 / IEC 62747 symbols as TikZ `\pic`s, generated by Glyphwright
(`~/Projects/glyphwright`). Both files belong together and must
stay in the same folder:

| file | content |
|---|---|
| `glyphwright.sty` | the package: styles, signal switches, editable texts |
| `glyphwright-symbols.tex` | one `\pic` per symbol, loaded by the package |

## Use in a document

Put this folder on the TeX search path, e.g. with a `.latexmkrc` next to the
document (path relative to the document):

```perl
ensure_path('TEXINPUTS', '../../template/glyphwright//');
```

or `TEXINPUTS=~/hids/template/glyphwright//: xelatex doc.tex`. Then:

```latex
\usepackage{glyphwright}                 % loads TikZ
\begin{tikzpicture}[x=1mm, y=1mm]        % symbols are drawn in millimetres
  \pic at (0,0) {gw/cb};
  \pic[gw/signals={udpp, id_p}] at (30,0) {gw/vsc2-sig};
\end{tikzpicture}
```

Loading it as `\usepackage{glyphwright/glyphwright}` from a parent folder does
not work: the package finds `glyphwright-symbols.tex` only on the search path.
Use only this one `glyphwright.sty` in a document; the copies in Glyphwright
build folders hold only the symbols of their own diagram.

## Contents and regeneration

The manifest symbols of Glyphwright plus every symbol used by the diagrams
listed in the command below. After symbol changes, or for a new diagram, run in
the Glyphwright repository:

```bash
python -m glyphwright texlib ~/hids/template/glyphwright \
  --sld ~/hids/presentation/amwatt_20261001/figures/src/smp_level_1.yaml
```

(add one `--sld` per diagram, or plain ids such as `cb-r90`). Signal keys
(`gw/signals`, `gw/hide signals`, `gw/show signals`, `gw/hide names`,
`gw/show names`, `gw/text`) are described in Glyphwright `docs/usage.md` and
`docs/converter-spec.md`.
