\section{Introduction}
Use this template as the starting point for technical reports. Set the metadata
commands in the preamble (\texttt{\textbackslash reporttitle}, \texttt{\textbackslash reportdocnumber},
\texttt{\textbackslash reportrevision}, \dots) and the cover page, headers and footers update automatically.

\subsection{Structure}
A report typically contains: an executive summary, an introduction and scope, the
technical body organised into sections, conclusions and recommendations, and
references or appendices.

\section{Formatting elements}

\subsection{Lists}
\begin{itemize}
  \item Bulleted items use the amber accent marker.
  \item Keep each point concise and self-contained.
\end{itemize}

\begin{enumerate}
  \item Numbered steps for procedures or ordered arguments.
  \item Second step.
\end{enumerate}
